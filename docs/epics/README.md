# Épicas del backend

Las épicas están registradas como issues GitHub con prefijo `[EPIC]`. Este archivo sirve de índice y no reemplaza el estado vivo de los issues.

## Alcance por incremento

- **Núcleo (Corte 2):** identidad básica, catálogo, establecimientos, registro de precios, confiabilidad/moderación, comparación y carga inicial manual.
- **Módulo comercial (Corte 3):** perfil de comercio, precios oficiales, promociones e integración de fuentes.
- **Fuera del MVP:** alertas de bajada de precio, automatización SIPSA y scraping de catálogos.

## Criterios transversales de cierre

- Requisitos y criterios de aceptación enlazados.
- Reglas de negocio con TDD.
- OpenAPI actualizado cuando cambia la API.
- Protección de datos personales.
- Neutralidad de comparación.
- Revisión de código por otro integrante.
- Evidencia real de ejecución, sin declarar pruebas no corridas.
